Firmware for motorized roller blinds: ESP32-C6 blind modules (`driver`) and an nRF52840 remote, in Rust `no_std` (esp-hal/embassy).

## Design docs

The design and project docs live in `~/Documents/School/s1/b2` (a school assignment, written in Dutch). Its `CLAUDE.md` holds the current hardware and behavior decisions, which take precedence over this repo's README. `1-ontwerp.md` has the design: pin tables, radio protocol, button handling, state diagrams and task layout.
